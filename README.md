# 🐄 AI-Based Cattle Breed Prediction System

An AI-powered Computer Vision application that automatically detects and classifies cattle breeds from images using **Python, OpenCV, YOLOv8, and Machine Learning**. The system helps improve livestock management by providing fast and accurate breed identification.

## 🚀 Features

- Detects cattle from uploaded images
- Classifies different cattle breeds
- YOLOv8-based object detection
- Image preprocessing and feature extraction
- Machine Learning & CNN model training
- Simple graphical user interface
- Fast and accurate breed prediction

## 🛠️ Technologies Used

- Python
- OpenCV
- YOLOv8
- Machine Learning
- Convolutional Neural Networks (CNN)
- NumPy
- Pandas
- Scikit-learn

## ⚙️ Workflow

1. Upload a cattle image.
2. Detect the cattle using YOLOv8.
3. Preprocess the detected image.
4. Extract image features.
5. Predict the cattle breed using the trained ML/CNN model.
6. Display the predicted breed and confidence score.

## ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/sannith86/AI-Cattle-Breed-Prediction.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
